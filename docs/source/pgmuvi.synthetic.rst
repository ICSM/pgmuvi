pgmuvi.synthetic
================

The public helpers in this module generate analytic sinusoidal signals with
optional observational noise and return ready-to-use
:class:`~pgmuvi.lightcurve.Lightcurve` objects.  They do not draw from a
Gaussian-process prior or posterior.

See :doc:`notebooks/tutorial_synthetic` for a maintained, executable walkthrough
covering all four generators, reproducibility, noise modes, and chromatic
signals.
